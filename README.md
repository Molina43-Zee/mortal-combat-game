# Mortal Arcade Clash

A compact browser fighting game inspired by classic arcade fighters like Mortal Kombat.

Features:
- Local two-player controls
- Pixel-art inspired fighters with class-specific silhouettes
- Punch, kick, special move, block, and jump
- Combo chain tracking and super meter
- Impact flashes and generated sound effects
- Arcade-style intro and KO screens
- Wide arena with retro neon background

Controls:
- Player 1: A / D move, W jump, S block, J punch, K kick, L special
- Player 2: Left / Right move, Up jump, Down block, N punch, M kick, , special

How to run:
- Open `index.html` in a browser, or serve the folder with a small local server.

Example:
- `python3 -m http.server 8000` then open `http://localhost:8000`

This is a playable prototype built with HTML5 Canvas and JavaScript.
